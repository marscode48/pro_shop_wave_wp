# PROSHOPWAVE - WordPress Theme

自動車カスタムパーツ店のECサイト専用に開発されたオリジナル WordPress テーマです。チューニングプロショップを表現したビジュアルと、WooCommerce対応の機能性を両立しています。

## 特長

- Swiper.js ＆ GSAP アニメーション
- WooCommerce 対応
- モバイルファースト設計
- パフォーマンス重視の軽量コード

## 開発環境

- WordPress 6.x 以上
- PHP 7.4 以上
- Local by Flywheel 推奨

## ディレクトリ構成（抜粋）
proshopwave/
├── css/
├── js/
├── scss/
├── template-parts/
├── functions.php
└── style.css

## 推奨プラグイン

- ACF Pro
- WooCommerce

yarn install
yarn run dev    # 開発用
